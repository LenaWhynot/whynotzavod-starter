# Контент-завод

Личная панель для коротких видео. В ней можно собрать идеи, написать сценарий с несколькими хуками, загрузить готовые версии, проверить их и запланировать выход.

## Сделать свою копию

1. На странице этого репозитория нажми **Use this template → Create a new repository**. Выбери свой аккаунт и создай приватный репозиторий.
2. Клонируй свой репозиторий через **Code → Local** и открой его папку в терминале.
3. Убедись, что установлен Node.js 22.13 или новее, и запусти:

   ```sh
   node --version
   npm start
   ```

4. Открой [Контент-завод](http://127.0.0.1:4329). Он начнёт с пустой базы. Устанавливать пакеты и заводить аккаунты сервисов для локального запуска не нужно.

Остановка — **Ctrl+C** в терминале. Повторный `npm start` откроет те же данные.

## Первый ролик

1. В **Банке идей** добавь свою заметку или вставь ссылку на референс. У карточки нажми **Создать сценарий**. Можно сразу открыть **Сценарии → Новый сценарий**.
2. Заполни текст и хуки по одному на строку. На этапе **Снять** кнопка **Добавить в суфлёр** копирует текст и хуки.
3. После монтажа открой нужный сценарий и нажми **Добавить видео**. Выбери готовый MP4 до 50 МБ и, если нужно, хук. Можно добавить несколько файлов по одному.
4. В карточке версии нажми **Одобрить → В календарь**. Календарь предложит ближайший свободный слот Trial на 09:00, 12:00 или 15:00 МСК. Слот можно перенести в самом календаре.

В **Правилах и настройках** можно сохранить свои правила голоса и оформления. Календарь хранит план. В соцсети ролик нужно выложить вручную. Поиск трендов, генерация сценариев, монтаж и сбор статистики требуют своих интеграций. В шаблоне эти интеграции не подключены.

## Где лежат материалы

SQLite и загруженные MP4 хранятся в каталоге `data/`. Каталог исключён из Git. Для резервной копии останови приложение и скопируй его целиком. Путь можно задать переменной среды `CONTENT_FACTORY_DATA`, порт — `CONTENT_FACTORY_PORT`.

Приложение слушает только `127.0.0.1` и рассчитано на личную работу на одном компьютере. Для командного доступа через интернет понадобится отдельная настройка входа и хостинга.

`npm test` проверяет хранилище, ревью, календарь и запись нового сценария с видео.
